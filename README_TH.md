# Monster Spin Jackpot 777 · เว็บเช็กคะแนน

## ในโฟลเดอร์มีอะไร
- `index.html` หน้าเว็บทั้งหมด
- `api/bs.js` ตัวกลางดึงข้อมูลจาก Robinhood Chain ใช้เป็นตัวสำรองเวลาเบราว์เซอร์ดึงตรงไม่ได้
- `package.json` ไฟล์ตั้งค่าเล็กๆ ให้ Vercel รู้จักโปรเจกต์

## วิธีอัปขึ้น Vercel
แบบที่ 1 (แนะนำ ใช้ได้ครบทุกฟังก์ชัน):
1. ติดตั้ง Node.js แล้วพิมพ์ `npm i -g vercel`
2. เข้าโฟลเดอร์นี้ แล้วพิมพ์ `vercel --prod`

แบบที่ 2: อัปโฟลเดอร์นี้ขึ้น GitHub แล้วกด Import ใน Vercel

ถ้าอัปแค่ไฟล์ `index.html` ไฟล์เดียว เว็บยังทำงานได้ถ้า explorer ยอมให้เบราว์เซอร์ดึงข้อมูลตรง แต่จะไม่มีตัวสำรอง

## ลองดูหน้าตาก่อนอัป
เปิด `index.html?demo` จะใช้ข้อมูลตัวอย่าง (มีป้าย DEMO DATA)

## ตั้งค่าคะแนน (สำคัญ)
แก้ในส่วน `CONFIG` ด้านบนของ `<script>` ใน `index.html`
- `scoreTraits` ถ้า metadata มี trait ชื่อ Score หรือ Points เป็นตัวเลข เว็บจะใช้ตัวเลขนั้นเลย
- `points` ตารางคะแนนของแต่ละไอเทม เช่น `"Gold Coin": 50, "Cursed Skull": -77`
- `keywords` ใช้เดาคะแนนจากชื่อไอเทม ถ้าไม่มีในตาราง (เว็บจะบอกว่าเป็นคะแนนประมาณ)
- `ignoreTraits` trait ที่ไม่นับคะแนน เช่น Background
- `tiers` ระดับคะแนน เช่น JACKPOT 777 ขึ้นไป
